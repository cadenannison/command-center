# 0141. The "Synced 0 items: ..." counts of the feed adapter are logged, not shown on the card

Status: accepted; open for the project manager (see Revisit)

Context: Task L1 asks that when a LearningSuite sync keeps nothing, the ok message say why ("Synced 0 items: 3 feeds, 12 events in the feeds, 0 inside the window"). The text "Synced N items" is built in `services/sync.py` and again in `workers/normalizer.py` (which overwrites a report's message for status `ok`), from the number of rows `replace` wrote. `SourceAdapter.fetch` returns `list[Event]` and has no channel for a message, `ValidationResult.message` belongs to `validate`, which has no window, and adapters may not import `services.horizon`. The card's layers are adapters and `app.py`.
Decision: `IcalFeedAdapter.fetch` logs exactly that sentence (`zero_items_message`, passed through `core.redact.redact`, counts only, with `source` in `extra`) at INFO when it returns no events, and logs nothing otherwise. The card text is unchanged. `command-center diagnose learningsuite` (0140) gives the same counts and the reason, on demand.
Alternative: Add an optional note to the fetch result (a change to the `SourceAdapter` port in `core/ports.py`, to `SyncService`, to the distributed `SyncReport` and to `normalizer.py`; it widens a published job and report shape); or have `validate` fetch with a hard-coded window (duplicates `horizon_window` in the adapter, and the message would show at connect time only, not at every sync).
Reason: The change that would put the words on the card crosses the port, two services and the distributed report, all outside this card's layers and in code other sessions edit. The log line and the subcommand answer the question without that.
Where: `IcalFeedAdapter.fetch` and `zero_items_message` in `src/command_center/adapters/ical_feed.py`; tests `test_a_sync_that_keeps_nothing_logs_counts_and_no_url_or_title`, `test_a_sync_that_keeps_something_logs_no_zero_message` in `tests/test_ical_diagnose.py`.
Revisit when: The project manager wants the sentence on the card: a follow-up card spanning `core/ports.py` (an optional note on the fetch result), `services/sync.py`, `workers/normalizer.py` and the report contract, which supersedes this record.
