# 0407. Under CC_BIND_ALL a loopback Host is the local user only from a trusted socket peer

Status: accepted; narrows 0072 and 0090 (the compose network is no longer trusted by default)

Context: a request is local when its Host names localhost and carries no proxy header. That is sound when the server binds 127.0.0.1. Under `CC_BIND_ALL=1` (the compose api service) the listener is reachable from every container on the network, and the Host header is the caller's to choose, so any container skipped pairing (audit X04).
Decision: when `bind_all` is set, `DeviceAuthMiddleware` demotes a request the Host rules call LOOPBACK to REMOTE unless `peer_is_trusted(scope["client"][0], trusted_peers)`. `trusted_peers` comes from `CC_TRUSTED_PEERS` (comma separated IP addresses or CIDR ranges), default empty, so under Docker everything needs a device token until the operator names a peer. A missing client address is untrusted. An invalid entry stops startup. With `bind_all` false nothing changes. The Host check stays in both modes. `classify_request` is unchanged.
Alternative: trusting the Docker bridge range by default (every container on it would become the owner); dropping `CC_BIND_ALL` (the published port would not work); a shared local token for the browser (larger change).
Reason: the socket peer is the one input the caller cannot write; the Host and forwarding headers are not evidence of locality.
Consequences: under Docker the Mac's own browser must be a listed peer: it cannot pair like a phone, because the pairing page and the settings writes are local-only. With the list empty the compose stack serves no usable UI, so the operator must set the value before first use, and `scripts/smoke-distributed.sh` (unchanged here) gets 401 until then. The address the container sees for it depends on the Docker runtime and has not been measured; compose leaves `CC_TRUSTED_PEERS` unset. One new permanent settings key, `CC_TRUSTED_PEERS`. The ports are unchanged; `create_app` and `install_auth` gain two optional keyword arguments.
Where: `core/hosts.py` (`peer_is_trusted`), `config.py` (`trusted_peers`), `api/auth.py` (`DeviceAuthMiddleware`, `install_auth`), `api/factory.py`, `app.py` (`build_app`). Tests: `tests/test_core_hosts_peer.py`, `tests/test_auth_peer.py`.
Revisit when: the peer address for the Mac's browser under Docker is measured and stable, or a shared local token for the browser is wanted.
