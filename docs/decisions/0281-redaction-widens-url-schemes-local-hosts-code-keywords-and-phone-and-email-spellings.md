# 0281. Redaction widens URL schemes, local hosts, code keywords and phone and email spellings

Status: accepted; supersedes in part 0240 (the URL scheme list and the scheme-less URL host), 0242 (the keyword list and a code before its keyword), 0243 (the separators of a phone number) and 0244 (the spelled-out email brackets and the spaced "@")

Context: The same review found real secrets in shapes the rules missed: `ftp://`, `postgres://` and `s3://` URLs, `192.168.1.20/admin?key=x` and `localhost:8080/x`, `password 4821`, `token: 48213`, `cvv 123`, `4821 is your verification code`, `801,555,1234`, `801*555*1234`, `801x555x1234`, `bob @ example.com` and `bob{at}example{dot}com`.
Decision: (1) A URL is any scheme `[a-z][a-z0-9+.-]*://` up to whitespace (case-insensitive, the scheme sits at the start of a run of scheme characters, after any digits, `+`, `.` or `-` that begin it, which are kept: `1.https://x.io/a` gives `1.[url]`, `1x://y` gives `1[url]`; the search stays linear); `jdbc:postgresql://h/d` gives `jdbc:[url]`. A scheme-less URL may also be an IPv4 address or `localhost`, with an optional port of 1-5 digits, followed by `/`, `?` or `#`: the whole URL is `[url]` (`10.0.0.0/24` is `[url]` too; `localhost` alone is not). (2) The keywords of the code rule are `code`, `otp`, `pin`, `passcode`, `verification`, `password`, `passwd`, `token` and `verify` (optional plural, not inside a longer word) for 4-5 digits, and `cvv` and `cvc` (optionally followed by `2`) for 3-4 digits; the other rules of 0242 and 0260 are unchanged. (3) A code before its keyword: a run of 4-5 digits, not part of a longer number, date or decimal and not glued to a word, followed by up to five letter-only words and then one of the nine keywords: `[number] is your verification code`. The keyword is not consumed, so a code after it is found by the forward rule. (4) A 4-digit number that follows an all-capitals word of 2-6 letters (and a space) is a course number, not a code, unless that word is the keyword itself (the same holds for a course number such as `2420-001`: `pin 4821-993` is masked, review finding of task R3): `Verify PSY 1010` and `CS 2420 code review` stay, `Your PIN 4821` is masked. (5) A phone number of the 3-3-4 shape (`801,555,1234`, `801*555*1234`, `801x555x1234`, any mix, no spaces) is `[number]` when it is not preceded by a letter, digit or comma and not followed by a digit or a comma and digit, so `1,234,567`, `1,801,555,1234` and `rooms 101,102,103` stay. (6) An email may be written with spaces around the `@` (`bob @ example.com`, `bob@ example.com`) when the domain is dotted and ends in 2-24 letters; a marker is never the local part; `Lunch @ noon` and `Meet @ 3.30pm` stay. The spelled-out forms accept braces as well as brackets and parentheses: `{at}`, `{dot}`.
Alternative: Mask every 3-4 digit run after any keyword (rejected: cvv is the only 3-digit code on the list, and `room 101` would be masked after `verify`). Mask a code before its keyword at any distance (rejected: five words, as 0242). Treat every `@` with spaces as an email (rejected: `Lunch @ noon`). Allow `,`, `*` and `x` between any digits of a phone (rejected: `1,234,567` is a number and `x` is a letter). Judge course numbers by an uppercase prefix list (rejected: unbounded).
Reason: Each rule adds one shape from the review and no more, with the same limits (five words, 3-4 or 4-5 digits, a dotted domain) the older rules use.
Consequences: New false positives, kept on purpose: a year or room number within five words of `password`, `token` or `verify` (`Verify room 2031 booking`), before or after the keyword (`2031 verify`), unless an all-capitals word precedes it; `Class @ Marriott.Library` and other `word @ Word.Word` text as an email; `10.0.0.0/24` as `[url]`. `ftp://example.com/a` was kept before and is masked now, and `hxxps://example[.]com`, which was a known gap, is masked by the scheme rule as a side effect. `barcode 4821 pin` gives `barcode [number] pin`.
Where: `src/command_center/core/redact.py` (`_URL`, `_BARE_URL`, `_SPACED_EMAIL`, `_AT`, `_DOT`, `_CODE`, `_CARD_CODE`, `_CODE_BEFORE`, `_mask_code`, `_PHONE_ALT`), `tests/test_redact_agenda.py`, `docs/contracts/core.md` (Redaction).
Revisit when: A real title is damaged by one of the new keywords or `word @ Word.Word`, or a code is seen before a keyword that is not on the list.
