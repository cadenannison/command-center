# 0082. The decision index is generated, and `gen_docs.py` runs it

Status: accepted; the script name and how `gen_docs.py` loads it are superseded in part by 0087

Context: Task 4a. There are 80 records and `Status:` lines are free text ("accepted; item 12 (c) is superseded by 0060 ..."), so finding what replaced what meant reading them all. The card asks for `scripts/gen-decision-index`, wired into `gen:build` and `gen:check`, writing `docs/generated/decision-index.md` and linked from `docs/MAP.md`.
Decisions:
1. **The script is `scripts/gen-decision-index`** (no extension, executable, Python). `build_index(directory)` returns the table: number, title (linked to the file), status, superseded by. Files not named `NNNN-*.md` (`tooling-versions.md`) are not records. A record whose first line is not `# NNNN. Title` with the file's number, that has no `Status:` line, or that shares a number with another is an error naming the file, and the script exits 1.
2. **Status** is the first word of the `Status:` line (`accepted`, `superseded`). **Superseded by** merges two sources: the record's own line (`superseded by 0024`, `partly superseded by ...`, with "and"/commas for several), and any other record whose line says `Supersedes ... NNNN` (only up to the end of that sentence, so a number in "Extended by 0056" is not counted). A replacement named by both is listed once. A record whose status keyword is not `superseded` but has a replacement is shown as "NNNN (in part)", because it still stands apart from the clause that was replaced.
3. **Wiring.** `gen_docs.py` loads the script with `SourceFileLoader` (a hyphenated, extension-less file cannot be imported by name) and adds `decision-index.md` to the files it renders, so `mise run gen:build` writes it and `gen:check` fails when it is stale, missing or orphaned, with the existing byte comparison and messages. The script also runs alone (`scripts/gen-decision-index [--check]`). `mise.toml` is unchanged.
4. **Tests** (`tests/test_gen_decision_index.py`) build fixture directories in `tmp_path`: order and links, skipped files, each supersession form, the "in part" rule, once-only listing, the sentence cut, pipes in titles, malformed and duplicate records, check mode, and that every real record parses. They do not compare with the committed file: that is `gen:check`.
Alternative: (a) A second mise step instead of `gen_docs.py`: `gen_docs.py --check` would call `decision-index.md` orphaned, so it would also need a skip list. (b) A structured `Superseded-by:` field in every record: it is the better data, but it means editing every old record, and `AGENTS.md` lets old records change only on their Status and Sources lines. (c) Name the file `gen_decision_index.py`: importable and linted, but the card named the file.
Reason: one generator mechanism for every file under `docs/generated/`.
Where: `scripts/gen-decision-index`, `scripts/gen_docs.py`, `docs/generated/decision-index.md`, `tests/test_gen_decision_index.py`.
Revisit when: a record needs a supersession the two patterns cannot say (add the sentence form, or adopt (b)); the extension-less name makes ruff and pyright skip the file by default (the file was checked by hand with both; adding it to `[tool.ruff] extend-include` is a `pyproject.toml` change that needs asking).
