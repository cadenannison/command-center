# 0286. An engineer agent writes its decision record in the card's range, or stops and asks for one

Status: accepted. Supersedes 0254 in part (only its last sentence: that the agents list a judgement call in the report when they have no decision number).

Context: 0254 told `adapter-`, `services-`, `storage-`, `api-` and `web-engineer` to "list the decision in your report" when they had no decision number. AGENTS.md says every judgement call, deviation or choice between real alternatives needs a numbered record in `docs/decisions/`, and `docs/decisions/README.md` says a card that gave no number means ask the project manager. A call listed only in a report is lost when the session ends, and nothing makes the human write it down.
Decision: Each of the five agent files now says: a judgement call needs a numbered decision record; when the card gives a number range, write the record in it, lowest unused number first; when the card gives none, stop and ask the project manager for a range, and do not list the call in the report instead. Nothing else in the five files changes. No `CLAUDE.md` file repeated the old wording (checked: the root file and the seven layer files), so none needed an edit; 0254 is the only other place, and its Status line points here.
Alternative: Keep the report-only rule (rejected: it contradicts AGENTS.md and loses the decision). Let an agent pick the next free number itself (rejected: another session may be writing the same number, which is why the range belongs to the project manager; README). Stop for every small choice (not asked: the rule only applies to a real judgement call, as AGENTS.md defines one).
Reason: One rule in every place, the same as AGENTS.md and the decisions README, with the number always coming from the project manager.
Consequences: An agent can now stop a task to ask for a range, which costs a round trip; a card should give a range with the task. `domain-engineer` has no sentence on this at all, so it relies on AGENTS.md alone; that is left as it is because the card named five agents.
Where: `.claude/agents/adapter-engineer.md`, `.claude/agents/api-engineer.md`, `.claude/agents/services-engineer.md`, `.claude/agents/storage-engineer.md`, `.claude/agents/web-engineer.md`.
Revisit when: Cards stop carrying ranges (then agents could take the next number from a shared allocator), or `domain-engineer` is given the same sentence.
