# 0008. UI is Jinja2 + HTMX; menu-bar launcher via rumps

Status: accepted

Context: One-language stack, no JS build chain, local use only.
Decision: Server-rendered Jinja2 templates with HTMX for partial updates. A macOS menu-bar launcher uses rumps (macOS-only `desktop` extra).
Consequences: Views are thin and call services. rumps is imported only in `adapters/menubar_rumps.py`; the `desktop` extra is marked darwin-only so Linux CI still installs. The mobile client is a separate repo and uses /v1.
