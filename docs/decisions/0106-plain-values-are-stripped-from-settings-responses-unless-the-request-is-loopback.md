# 0106. `values` is stripped from `/v1` settings responses unless the request is loopback

Status: accepted; narrows 0100

Context: Decision 0100 put the stored non-secret values (Apple ID, Canvas URL, weather coordinates) in `SourceSettings.values`, and `GET /v1/settings` returned them to every caller, a paired phone included. AGENTS.md rule 5 and `.claude/rules/layers.md` say the settings API is write-only. The project manager approved `values` for the Mac's own page and asked that a phone not receive them.
Decision: `DeviceAuthMiddleware` sets `scope["state"]["loopback"] = True` when the Host rules classify the request as loopback (no proxy header; decision 0057). The settings routes read it through `deps.LoopbackDep` and return `values: {}` for any request without the flag. That covers `GET /v1/settings` and the `SourceSettings` that `DELETE /v1/settings/{source}` returns (a phone cannot make that call, so this is a second line). The flag is absent when the middleware did not run, so a request with no classification counts as remote: it fails closed. The response shape does not change: `values` stays in the schema and is `{}` for a phone; `keys` still reports `set` and `last4` for every key. The web page is loopback-only and keeps its prefill (it reads the service, not `/v1`). The `values` field description in `openapi.json` says so.
Alternative: Remove `values` from `/v1` altogether (breaks the shape the web page and the loopback API client use, and the mobile contract would lose a field it may later want); or compute `values` per caller inside `SettingsService` (the service has no notion of the request).
Reason: The caller's exposure is known only at the edge, where the middleware already decides it, so the edge marks it and the route applies it. Keeping the field and emptying it is not a breaking change.
Where: `LOOPBACK_STATE_KEY` and the flag in `src/command_center/api/auth.py`; `is_loopback`, `LoopbackDep` in `api/deps.py`; `_shown` and the two routes in `api/settings.py`; the field description in `services/models.py`. Tests: `tests/test_settings_values_remote.py`.
Revisit when: A phone screen needs the Canvas URL or location (add a scoped read then, with its own decision), or another route returns a plain value (it must use the same flag).
