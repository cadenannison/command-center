# 0160. Chat providers may be local over http; every other host must be https and public

Status: accepted. Partly superseded by 0220 and 0221.

Context: `require_https_public` refuses http and every private address, which is right for a feed or a cloud API but wrong for Ollama (`http://localhost:11434`) and for llama.cpp, LM Studio or vLLM on the user's LAN. None of them has a certificate. The address is written through the settings route, which is loopback only, so only the user can set it.
Decision: `core/urlcheck.py` gets `require_chat_base_url`. http or https; no userinfo, query or fragment (a key never rides in a URL); localhost, `*.localhost`, `*.local`, a single-label name, loopback, RFC1918 and IPv6 ULA may use http; any other host goes through `require_https_public`. Link-local, the cloud-metadata names and IPs, and unspecified or multicast addresses are refused whatever the scheme, and so is CGNAT (decision 0168). The userinfo message now says `must not embed credentials`, so a message never contains the word that a test greps for. The adapters check the URL again on every call and open the connection with `follow_redirects=False`, so a redirect cannot reach a host that was never checked. Core does no DNS; the adapter resolves every name that is not a literal address, except `localhost`: a public-looking name must resolve only to public addresses, and a local name (`*.local`, a single-label name) is refused when any address would be refused as a literal (link-local, metadata, unspecified, multicast, or public over http). `localhost` and `*.localhost` are not resolved (`adapters/chat_http.py`).
Alternative: Allow http for any host the user types (a typo or a hostile paste would send the agenda in clear text across the internet); allow private addresses over https only (Ollama does not serve https); add a per-provider "I trust this" flag (a second way to reach the same exception).
Reason: The exception is exactly "the address is on this machine or this network", which cannot be reached by a stranger and does not cross the internet, and the always-refused list stays the one place that blocks metadata endpoints.
Where: `src/command_center/core/urlcheck.py`; `adapters/chat_http.py` (`checked_base_url`, `post_json`); `tests/test_urlcheck_chat.py`, `tests/test_chat_adapters.py`.
Revisit when: A provider needs a non-local http host, or core gains a resolver port that lets the guard check a resolved address itself.
